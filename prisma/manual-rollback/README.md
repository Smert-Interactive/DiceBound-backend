# Исходные down.sql

Архив ручных обратных скриптов из первоначальной реализации БД.
Prisma Migrate не выполняет эти файлы.

Скрипты удаляют таблицы и данные, требуют обратного порядка 004 -> 001
и не согласуют результат с `_prisma_migrations`.
Штатные исправления выполняются новыми миграциями.
Порядок перехода и ограничения описаны в [инструкции БД](../../docs/database.md).
